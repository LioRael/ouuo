# First release plan

1. Establish pnpm/Turbo, strict TypeScript, formatting, typed lint, unit and browser checks. Install the official UI SDK skill and read the installed-version component documentation.
2. Implement the piano's original score, deterministic timing judgement and Web Audio voice lifecycle with tests before connecting the interface.
3. Build a branded collection homepage and an immersive plonko with free play, original guided song, scoring, keyboard/multitouch input, sustain, volume, mute and accessible settings.
4. Add separate, honestly labelled workshop entrances for Tiny Studio and Pocket Arcade. Keep their future scope and acceptance criteria in the roadmap.
5. Verify every app independently, browser interactions and audio rendering, responsive screens, reduced motion, SDK agent actions and keyboard focus. Document deployment and contributor workflow.

No remote publication, production deployment or Git push is part of this local delivery.
